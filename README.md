# MAISON — Interactive Fashion Digital Showroom

A premium, futuristic, and highly interactive fashion e-commerce digital experience inspired by the **Nike Try the Look** interactive showroom.

---

## 🌟 Key Features

### 1. Minimalist & Futuristic Aesthetic
- Clean, warm ivory (`#FAF9F6`) and off-white studio palette.
- High-fashion editorial art direction with subtle borders, generous whitespace, and luxury typography with wide letter-spacing.
- Glassmorphism overlays (`backdrop-blur-xl`) with soft ambient dropshadows.

### 2. Main Hero Showroom Lineup
- Side-by-side realistic fashion models standing in a clean minimalist studio.
- Models display complete head-to-toe curated ensembles (hoodies, blazers, trousers, coats, sneakers, accessories).
- Interactive card hovering, smooth zoom effects, and layout animations.

### 3. Interactive Outfit Selection & Hotspots
- **Model Focus Mode**: Clicking any model smoothly opens the high-fashion studio showroom.
- **Pulsing Hotspots**: Concentric animated hotspots placed on individual garments and accessories (tops, outerwear, trousers, footwear, jewelry).
- **Interactive Tooltips**: Hovering over any hotspot reveals the item label.
- **Look Switcher**: Toggle effortlessly between multiple looks per model ("Look 1 of 2") with animated transitions.
- **Look Breakdown Panel**: Detailed garment inventory with piece-by-piece prices, total look valuation, and editorial fit notes.

### 4. Seamless Shopping Experience
- **Interactive Product Drawer**: Click any hotspot or piece thumbnail to open the slide-in product drawer without losing your showroom context.
- **Customization Options**: Live color swatches, size selectors, and quantity adjustments.
- **Add to Bag Animation**: Dynamic button state transitions with micro-interactions.
- **Slide-out Cart**: Real-time quantity controls, instant subtotal calculation, and checkout trigger.

### 5. Cinematic Transitions & Animations
- Staggered letter-by-letter loading screen with live percentage counter and split curtain reveal.
- Parallax scrolling editorial banner with dynamic depth transforms.
- Framer Motion FLIP layout transitions between showroom lineup and model focus views.

---

## 🛠️ Tech Stack

- **React 19** with **TypeScript**
- **Vite** for ultra-fast build and hot module replacement
- **Tailwind CSS v4** for clean modern utility styling
- **Framer Motion** for physics-based fluid spring animations and layout transitions
- **Zustand** for centralized, predictable state management
- **Lucide React** for icons

---

## 🚀 Getting Started

To launch the project locally:

```bash
# Navigate to the project directory
cd fashion-showroom

# Start development server
npm run dev

# Or build and preview the production bundle
npm run build
npm run preview
```
